# Telegram-бот

Бот разворачивается только на центральном сервере и читает состояние из
PostgreSQL. Команды, меняющие состояние роутера, выполняются только после
явного подтверждения и попадают в журнал команд.

Доступ к кнопкам «Проверить сейчас» и «Перезапустить sing-box» ограничивается
списком Telegram ID из `ROUTER_MONITOR_ADMIN_IDS`.

Кнопки MVP:

| Кнопка | Действие |
|---|---|
| Все роутеры | Сводка transport, sing-box, tun0 и иностранного IP по каждому роутеру |
| Карточка роутера | Последнее состояние, время проверки, uptime, RAM, load, VSZ/RSS и IP |
| Проверить сейчас | Запускает внеплановый health-cycle выбранного роутера |
| График нагрузки | Ссылка на Grafana с фильтром выбранного роутера |
| События | Последние изменения состояния и причины alert |
| Перезапустить sing-box | Двухшаговое подтверждение; выполняется только allowlisted-команда через reverse SSH |
| Переподключить туннель | Двухшаговое подтверждение; перезапуск reverse SSH запрещён без отдельного ACL |
| Обновить | Повторно читает данные без изменения роутера |

Нерабочий иностранный IP считается пользовательской неисправностью VPN даже
если процесс sing-box формально запущен. Process, procd и `tun0` показываются
как диагностические причины.
